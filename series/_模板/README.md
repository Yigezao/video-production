# 长篇/多期系列 · 复用图库

一本书拆很多期时，不要每期从零生图。先建一个系列图库，用户生成一次，后面智能体只读不重做。

## 目录

```text
series/<书名>/
  series.json                 28 期怎么分、每期用哪些图
  asset_manifest.json         每张复用图的身份、适用范围、不能怎么用
  assets/reusable/            用户生成的复用图（智能体只读）
```

建系列时复制 `_模板`，改名为书名。

## 复用图清单

每张图都要在 `asset_manifest.json` 里登记：

```json
{
  "id": "ENV_CITY_01",
  "file": "assets/reusable/env_city_01.png",
  "kind": "environment",
  "subject": "北京城 / 雪夜 / 城墙",
  "reuse": "all",
  "allowed_episodes": [],
  "avoid": "不要用于南京场景；不要当人物特写",
  "rights": "AI生成/公版",
  "prompt": "生成时用的提示词",
  "notes": ""
}
```

## 哪些能复用

**可以跨期复用：**

- 环境：城市、雪夜、山路、战场远景、宫殿外景
- 建筑：城门、奉天殿、长城、牢房、书房、旅店
- 天气/氛围：雪、雨、雾、烛光、油灯
- 物件：圣旨、奏折、地图、盔甲、刀、火铳、印章
- 群体剪影：士兵、百姓、官员群像，没有具体正脸

**不能随便复用：**

- 具体人物正脸/特写（朱元璋、朱棣、嘉靖……各是各的）
- 具体事件画面（靖难、土木堡、夺门），只能在本期或明确允许的期数用
- 和旁白季节/地点/身份矛盾的图（雪夜图不要配夏天，北京图不要配南京）
- 有现代物品、文字、水印、明显 AI 崩坏的图

## 智能体怎么用

1. 做 Step 2 前先读 `asset_manifest.json` 和 `series.json`。
2. 只在 `reuse=all` 或本期在 `allowed_episodes` 里时复用。
3. 每个复用场景写 `asset_id` 和 `image` 路径。
4. 不修改、不覆盖、不重新生成 `assets/reusable/` 里的图。
5. 图不对/缺图就停下问用户，不要拿“差不多的图”顶。
6. 没有图库的书，继续走 B / B1+B3。

## 5 秒规则

长篇系列不要用 5 秒/张。每期 4–6 张唯一图，30–90 秒/张，配卡片和推拉平移。
