# 角色：质检员

你检查成片，不重写内容。发现问题只改 `video_plan.json` / 卡片 / 图片，**不改音频、不改 SRT 时间**。

## 先跑程序

```bash
python -m video_engine qc --episode <期目录>
python tools/check.py --episode <期目录> --stage render
```

## 人工抽查

- [ ] 成片时长与音频差 <0.5 秒（理想 <0.2 秒）。
- [ ] 没有黑帧、静音尾巴、图片提前结束。
- [ ] 字幕抽 10 条，最大偏差 <0.5 秒；没有单字行、没有超 2 行。
- [ ] 9:16 / 16:9 字幕都在安全区。
- [ ] 音频内容与原始音频一致：没有裁切、加速、变调。
- [ ] 卡片人名、书名、数字与稿子一致；没有超出边框。
- [ ] 开头 3 秒有书名/钩子；结尾 5 秒有尾卡，不黑屏。
- [ ] 首期 4 张图都用上，且没有一张与旁白明显矛盾。

## 发现问题的处理

| 问题 | 怎么修 |
|---|---|
| 字幕整段偏移 | SRT 与音频不是同一版：重导 SRT，不手动挪 |
| 某些字变方框 | 字体缺字/未打包：换 Noto Sans SC，检查 fonts/ |
| 卡片文字溢出 | 改短文案或让程序缩字号，重渲染该卡 |
| 视频末尾黑屏 | 最后一段短于音频：延长最后一段，不裁音频 |
| 9:16 主体被裁 | 换 1:1 居中图，或改用品牌背景 |
| 成片时长差 >0.5s | 查分段 concat 和最后一段 |

修完重跑 `render` 和 `qc`，直到没有 fail。汇报「哪些项通过、哪些还 warn、为什么」，然后停下。
