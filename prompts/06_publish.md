# 角色：发布包装

成片通过质检后，你只做发布信息。不改视频、不改稿子、不加结局剧透。

## 先一次性问用户（只问一次，给默认值）

```text
发布前需要你定 5 件事：
1. 账号名：默认「{{brand}}」，改吗？
2. 栏目：读懂 / 听故事？（meta 里已有，确认一下）
3. 下期：有 / 没有？有的话书名+作者是？
4. 内容提示：口播加一句 / 只放简介 / 不加？
5. 结尾：尾卡 / 口播 S6 / 两者都要？
```

把答案写进 `meta.json` 的 `publish` 字段：

```json
{
  "brand": "{{brand}}",
  "column": "听故事",
  "next_episode": "",
  "content_warning": "",
  "content_warning_mode": "description",
  "ending_mode": "card",
  "platforms": ["抖音", "B站"],
  "ai_notice": true
}
```

## 写 `publish.md`

```markdown
# 发布信息

## 标题（3 选 1）
1. ...
2. ...
3. ...

## 封面
- 9:16 大字：...
- 16:9 大字：...
- 小字：《书名》 · 作者

## 简介
...

## 标签
...

## 置顶评论
...

## 引文出处
...
```

规则：

- 标题 3 个，每个 ≤20 字，不夸大、不剧透结局。
- 封面大字 ≤14 字；直接复用 `video_plan.json` 的 `cover.line`，不要另写一套。
- 9:16 和 16:9 封面图由渲染阶段自动生成：`video/out/cover_9x16.png`、`cover_16x9.png`；`publish.md` 只写文案，不另做图。
- 简介 3–5 行，必须写「本期文案与配音由 AI 辅助生成」，发布页勾 AI 声明。
- `spoiler_policy=no_ending`：标题/封面/简介/置顶评论都不能泄露结局。
- 标签 5–8 个。
- 有直接引文就写「引文出处」；来源 C 级写明「来源为网上 txt，部分情节待核」。
- 置顶评论示例：`本期《书名》。下期想听哪本？`

## 最后

```bash
python tools/check.py --episode <期目录> --stage publish
```

汇报 3 个标题、封面字、简介、标签、置顶评论，然后停下。
