# 02 画面与字幕规范 V1.0

> 视频的视觉不是另起一套，而是账号视觉的延伸：**墨、纸、朱砂、折角、声波。**
> 账号昵称未定，所有模板用 `{{brand}}`；栏目名「读懂 / 听故事」可直接用。

## 1. 画面总原则

1. **字幕是主角。** 画面负责氛围和信息，不抢字幕。
2. **慢。** 只有缓慢推近、平移、淡入；没有快切、抖动、闪白。
3. **少。** 15–25 分钟只换 7–10 次画面（V0）；不要每句都换。
4. **静。** 背景以纸纹、留白、折角为主；不要满屏插画。
5. **真。** 卡片文字来自稿子；不编人名、数字、结局。

## 2. 色板与字体

| 角色 | 色值 | 用法 |
|---|---|---|
| 墨 | `#17181C` | 深色底、正文 |
| 纸 | `#F5EFE3` | 浅色底、深底文字 |
| 朱砂 | `#C84630` | 折角线、强调、印章；面积 ≤5% |
| 铜 | `#B08A57` | 细线、编号、次级信息 |
| 灰纸 | `#D8CDBC` | 折角背面、分隔 |

- 标题：思源宋体 SemiBold；正文/字幕：思源黑体 Medium。
- 字体随程序打包，不依赖系统；不要用书法体、艺术字。
- 字幕统一：白字 + 2px 墨色描边；不用彩色字、渐变字。

## 3. 版式与安全区

### 3.1 9:16（1080×1920）

```text
┌──────────────────┐ 0
│  顶部安全 120     │
│                  │
│   主视觉/卡片     │ 120–1500
│                  │
│   下三分之一      │ 1250–1450（不挡字幕）
│                  │
│   字幕区          │ 1530–1660
│   （1–2 行）      │
│  底部安全 260     │
└──────────────────┘ 1920
```

- 字幕：Fontsize 64（60–68），MarginV 260，左右 80；每行 ≤14 汉字，最多 2 行。
- 下三分之一卡片：底边不低于 1450，避免和字幕重叠。
- 全屏卡片：文字在 120–1500 内，底部留 220。

### 3.2 16:9（1920×1080）

```text
┌────────────────────────────────────┐ 0
│  左右安全 120                       │
│                                    │
│        主视觉/卡片 120–840          │
│                                    │
│        下三分之一 680–820           │
│        字幕区 850–960               │
│        底部安全 120                 │
└────────────────────────────────────┘ 1080
```

- 字幕：Fontsize 64（60–68），MarginV 120，左右 120；每行 ≤20 汉字，优先 1 行。
- 下三分之一卡片：底边不低于 820。
- 全屏卡片：文字在 120–840 内。

## 4. 卡片类型

> 所有卡片只显示 `hold_seconds`（标题 4s、章节 2.5s、金句 5s、人物 8s、结尾 5s），到时切品牌背景；**不要为了覆盖整段句子把卡片挂 20 秒**。
> `lower_third` 是叠加在背景/插画上，不切整帧，也不挡字幕。

### 4.1 开场卡（title_card）

- 版式：纸底，左上栏目名，中部书名（宋体，120–150px），下一行钩子（黑体，48–56px），右下折角。
- 内容：`{{brand}}` 可放左上小字；栏目名「读懂 / 听故事」；书名；一句 ≤12 字钩子。
- 时长：3–5 秒；淡入，不缩放。
- 不要：作者大头照、原书封面、二维码。

### 4.2 章节卡（section_card）

- 版式：墨底或纸底；大号编号 `01`（铜/朱砂），章节名（宋体，72–90px），下一行 ≤16 字说明。
- 时长：2–3 秒；只在章节开始，全片最多 5–6 次。
- 章节名示例：`故事起点` / `第一次转折` / `至暗时刻` / `结局`。
- 不要：英文 STORY/CHAPTER、复杂插画。

### 4.3 金句卡（quote_card）

- 版式：纸底或墨底，中央一句 ≤18 字，宋体 64–80px；下方细线 + 出处小字。
- 时长：4–6 秒；一句话不换行，必要时缩字号。
- 用途：把主播判断/书中关键句单独拎出来。
- **出处规则**：直引必须写 `source`（第 N 章 / 原书某部分），观众能看到；`source_refs` 只是内部编号。转述写 `quote_type: paraphrase`，卡片角落标「转述」。
- **C 级来源**：只能转述，不能直引。
- 不要：把整段话塞进卡片；不要伪造出处。

### 4.4 人物卡（character_card）

- 版式：下三分之一；3–4 个人名（黑体 40–48px）+ 一句身份/作用（28–32px）。
- 时长：5–10 秒；旁白继续，不切音频。
- 不要：人物头像、AI 生成的真人脸；用文字卡。
- 事实来源：`map.json` 的人物表；没有就不做。

### 4.5 时间线卡（timeline_card）

- 版式：下三分之一或全屏；3–4 个节点，横向或纵向，节点 ≤8 字。
- 时长：6–10 秒；用于跨多年的故事或阶段回顾。
- 不要：超过 5 个节点；不要把时间线写成剧情复述。

### 4.6 尾卡（end_card）

- 版式：墨底；`{{brand}}` / 栏目名；一句「下期见」；一个互动问题；右下折角 + 印章。
- 时长：4–6 秒；不淡出到黑，最后 1 秒停在尾卡。
- 不要：二维码、求三连、夸张大字。

### 4.7 背景（background）

- 版式：纸底 + 极淡纸纹 + 右下折角；无文字，或只放栏目名小字。
- 时长：30 秒–4 分钟；用于没有卡片/插画的段落。
- 运动：缓慢推近 1.00→1.04，或轻微平移 2%。
- 不要：满屏纹理、动态噪点、强对比。

### 4.8 插画（illustration，V1-lite / V1）

**首期 V1-lite 只放 4 张**，位置固定：

1. 开场标题卡之后：交代环境/时代。
2. 第一次重大转折：人物做出选择。
3. 至暗/最大危机：代价最高的一刻。
4. 高潮或结局前：情绪落点。

- 每张停留 30–90 秒（不超过 2 分钟），配合缓慢推近/平移；不每句换图。
- 23 秒的测试段不放 4 张图（最多 1 张），否则每 5 秒一切，反而乱。
- 统一 1:1 或 4:3，主体居中，两个比例都能裁。
- 风格：纸感编辑插画、墨线、低饱和、少量朱砂点缀；无文字、无水印。
- 人物：优先背影、剪影、环境；不生成正脸特写。
- 文学：物件、风景、室内、光影。
- 网文：环境、地图、符号、势力标识；同一本书先做视觉设定（人物/场景/配色）。
- 非虚构：示意图、结构图、案例场景；不编数据。
- 负面：不要文字、不要原书封面、不要明星脸、不要具体画师风格。

## 5. 字幕规范

### 5.1 内容

- 文本来自 `final.txt`；SRT 只提供时间。
- 每行 14–16 汉字（9:16）/ 18–22（16:9）；最多 2 行/1 行。
- 单条 0.8–6 秒；长句在逗号处切，短条合并。
- 不出现单字行、标点行、连续三条同样句式。
- 数字、人名、书名保持稿子写法；不改写。

### 5.2 样式

| 项 | 9:16 | 16:9 |
|---|---|---|
| 字体 | Noto Sans SC Medium | 同 |
| 字号 | 64（60–68） | 64（60–68） |
| 颜色 | 白 `#FFFFFF` | 白 |
| 描边 | 2px 墨 | 2px 墨 |
| 阴影 | 无 | 无 |
| 位置 | 底部居中，MarginV 260（240–280） | 底部居中，MarginV 120 |
| 对齐 | 居中 | 居中 |

- 不做逐字弹出、不做卡拉 OK 高亮、不做花字。
- 如果背景很亮，给字幕加一条 60% 透明度的墨色底条（可选），不要加彩色块。

### 5.3 首尾

- 开头 3 秒：书名/钩子必须在画面或字幕里出现；不要「大家好」。
- 结尾 5 秒：尾卡 + 下期预告/互动问题；不要黑屏。
- 全程字幕与音频偏差 ≤0.5 秒；抽 10 条人工核对。

## 6. 运动与转场

| 运动 | 用法 | 参数 |
|---|---|---|
| 淡入 | 卡片出现/结束 | 0.3–0.5 秒 |
| 缓慢推近 | 背景/插画 | 1.00→1.04–1.06，整段 |
| 缓慢拉远 | 结尾/留白 | 1.04→1.00 |
| 平移 | 横向插画 | 2–4% 画幅 |
| 交叉淡化 | 场景之间 | 0.3 秒 |

- 禁止：快切、闪白、抖动、旋转、缩放弹跳、镜头光晕。
- 一次只用一个运动；不要同时推近 + 平移 + 淡入。

## 7. 封面/缩略图

- 用账号封面模板（纸底/墨底 + 书名 + 钩子 + 折角）。
- 9:16 缩略图从视频首帧取，叠加标题；16:9 单独排版，不拉伸。
- 缩略图大字 ≤12 字；不剧透结局；含结局的期标「含结局」。

## 8. 不要做

- 不要用 GPT 示例里的深青+金，另起一套视觉。
- 不要把 9:16 裁成 16:9，或反过来。
- 不要让 AI 生成中文卡片；文字全部程序绘制。
- 不要每句换图；15 分钟 7–10 次画面变化足够。
- 不要用原书封面、剧照、明星脸、具体画师风格。
- 不要把字幕做成逐字动画或彩色花字。
- 不要为了画面裁切/加速/改音量；音频是唯一基准。
